### **Loop** is used for continous repetations


# FOR LOOP


## when we know the number of iterations then we use for loop

Syntax : 
```
for(initilization ; condition ; update) {
    // for body
        }
```

Example : 
```java
class even {
    public static void main(String[] args) {

        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) {
                System.out.println(i) ;
            }
        }
    }
}

```
it exits the loop as the condition is false

1. direct print
2. condition  then print
3. condition , calculate then print
